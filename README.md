# SWYNEX - Final Data Science Project

## Overview

This project presents an end-to-end data science case study using a
student dataset.

The project combines data preparation, exploratory data analysis,
feature preprocessing, machine learning and model evaluation.

## Problem Statement

The objective is to analyze student-related factors and develop a
machine learning model to predict student academic outcomes.

## Dataset

The dataset contains 395 student records and includes demographic,
academic, family and social attributes.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Problem Definition
2. Data Loading
3. Data Preparation
4. Exploratory Data Analysis
5. Data Preprocessing
6. Feature Engineering
7. Model Training
8. Model Evaluation
9. Conclusion

## Exploratory Data Analysis

Six visualizations were created:

1. Number of Students by Gender
2. Distribution of Students by Age
3. Distribution of Study Time
4. Distribution of Previous Failures
5. Distribution of Student Absences
6. Student Pass/Fail Distribution

## Machine Learning

A Logistic Regression model was developed to predict student academic
outcomes.

The data was divided into training and testing sets using an 80/20
split.

Categorical variables were encoded using One-Hot Encoding and missing
values were handled using appropriate imputation techniques.

## Model Evaluation

The model was evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Conclusion

The project demonstrates a complete data science workflow from raw
data preparation and exploratory analysis to machine learning model
development and evaluation.
